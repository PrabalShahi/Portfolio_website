# Prabal Shahi Portfolio

A futuristic blue/cyan portfolio website.

## Run locally

Open `index.html` in a browser.

For local development with a static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to Vercel

Upload this folder as a project or push it to GitHub and import it into Vercel. No build command is required because this is a static HTML/CSS/JS site.
